# 雞蛋武士 Tinkercad 組裝教學 v1.5（2026-10-08）

國小五、六年級 Tinkercad 新手課程，3 節課（每節 45 分鐘）。用「生物與人物」現成零件組出一隻拿雙劍的雞蛋武士，重點練習 **對齊 L、縮放＋貼正面、握持** 三大技巧。完成的作品可以上傳到「成語大亂鬥」。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 教學網頁（GitHub Pages 直接開這個） |
| `雞蛋武士教學.html` | 單一檔版本，圖片已內嵌，下載後離線也能開 |
| `雞蛋武士_教案.html` | 老師用 A4 教案＋學習單 |
| `lesson-data.js` | 步驟、提示、常見問題、互動動畫 |
| `align-guide.js` | 🎯 對齊 L 完全攻略 |
| `anim-data.js` | 進階示範動畫（挖孔、工作平面） |
| `img/` | Tinkercad 實機截圖 |
| `build.py` | 重新打包單一檔：`python build.py` |

## 改內容之後

改了 `lesson-data.js`、`align-guide.js` 或 `index.html`，執行 `python build.py` 重新產生 `雞蛋武士教學.html`。
