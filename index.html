    1. 老師給你班級代碼和暱稱。打開 Tinkercad → 「擁有班級代碼的學生」→ 輸入代碼和暱稱。

      ③ 滑鼠怎麼用

      • 左鍵點一下：選取零件。 左鍵按住拖曳：移動零件；在空白處拖曳＝拉出選取框。

        ⭐ 三大關鍵技巧

        組裝時一定會遇到三個問題：「零件放不正」、「零件大小不合、貼不到臉上」、「劍沒拿在手上」。這三招就是答案，下面三段動畫都是真實操作畫面。

        A對齊（L）＝ 戴正
        1. 選兩個零件
        2. 按 L，等一兩秒
        3. 先點基準零件（釘住）
        4. 點「左右中間」「前後中間」
        5. 上下那排不要點
        B縮放＋貼正面 ＝ 合身
        1. 點白點 → Tab 看原本大小
        2. 三個數字乘同一個倍數
        3. Ctrl+↑ 抬到對的高度
        4. 對齊時點「左排最前面」→ 貼在臉上
        C握持 ＝ 穿過去
        1. 先轉好武器角度
        2. 手＋武器 → L
        3. 先點手，再置中
        4. 用「透明」檢查柄在手裡

        📤 匯出角色，帶去玩美食冒險家

        做好的雞蛋武士可以變成遊戲角色！上傳 3D 角色後，可以玩美食冒險家全部 5 關（用火柴人或自己畫的角色只能玩第 1、2 關）。

        一句話：Tinkercad 右上角「匯出」→ 選 .OBJ → 下載到一個 zip → 不要解壓縮，整個 zip 拖進美食冒險家的「⬆ 上傳 3D（進階）」。
        匯出→.OBJ→zip（不要解開）→⬆ 上傳 3D（進階）

        ① 要用哪種格式？

        格式推薦有顏色說明
        .OBJ⭐ 首選✅下載的是 zip（裡面有 tinker.obj 和 obj.mtl）。顏色存在 .mtl 裡，所以整個 zip 直接上傳，不要解開。每個零件會分開，遊戲才認得手和腳。
        .GLB可以✅單一檔案、有顏色。OBJ 有問題時再改用它。
        .STL❌ 不建議❌沒有顏色，角色會變成一整隻橘色。
        .SVG❌ 不能用—這是給雷射切割用的平面圖。

        遊戲也接受 .obj＋.mtl 兩個檔一起選，但整個 zip 最不容易出錯。

        ② 匯出前檢查：手、腳、帽子要分開

        美食冒險家會看「零件的位置」自動決定誰負責什麼動作：

        🥚 身體中間最大的那塊（蛋）
        ✋ 手身體左右兩側，會擺手、揮武器。拿武器、比較長的那隻手負責攻擊。
        🦶 腳身體下方，會走路。
        ⛑️ 頭頂配件帽子、皇冠這類在頭頂的零件。
        ⚠️ 「群組」會把零件融成一塊。如果整隻武士群組成一個，手和腳就黏在身體上，動不起來。
        1. 選整隻武士，按 Ctrl＋Shift＋G 取消群組。
        2. 重新分成幾個小群組（每組選好後按 Ctrl＋G）：
          • 身體組：蛋、眼睛、鬍子等臉部裝飾
          • 右手組：右手＋握著的劍
          • 左手組：左手＋握著的劍
          • 左腳、右腳：各自一個，不要和身體群組
          • 帽子：自己一個
        3. 每一組都要開「多色」，不然顏色會變成一樣。
        4. 角色正面朝「前」（視角方塊上寫「前」的那一面），站在工作平面上，不要躺著。
        5. 轉一圈檢查：手、腳不要整塊埋進身體裡。輕輕碰到可以，最好留一點點縫。

        ③ 匯出步驟

        1. 點空白處，不要選任何零件。
        2. 按右上角「匯出」。
        3. 「包含」選設計中的所有物件（英文：Everything in the design）。不要選「選取的形狀」，以免少了零件。
        4. 在「用於 3D 列印」那一排點 .OBJ。
        5. 瀏覽器會下載一個 zip，檔名通常是設計名稱。
        6. 檔案在「下載」資料夾，不要解壓縮。
        💡 繁中介面的按鈕字樣可能和這裡略有不同，以畫面為準。英文介面是 Export → Everything in the design → For 3D Print：.OBJ。

        ④ 上傳到美食冒險家

        1. 打開美食冒險家：cona0815.github.io/eggeat
        2. 右邊「我的角色」→ 點 ⬆ 上傳 3D（進階）。
        3. 把 zip 拖進黃色框，或點黃色框選檔案。
        4. 出現 ✔ 和「手 ×2、腳 ×2」之類的辨識結果，就成功了。
        5. 按「走路／跳躍／攻擊／揮手／跳舞」預覽動作。
        6. 方向不對時：轉向（每按一次轉 90°，轉到臉朝前）；扶正（角色躺著或倒立時按）。
        7. 角色會記在這台電腦的瀏覽器裡，下次打開還在。換電腦要重新上傳。

        ⑤ 常見問題

        狀況原因解法
        手腳不會動，整隻一起晃整隻群組成一塊照 ② 拆成小群組再匯出
        角色全身同一個顏色用了 STL，或解壓縮後只上傳 .obj改用 OBJ 的 zip 整包上傳
        角色躺著、背對匯出時方向不對按「扶正」「轉向」，或回 Tinkercad 讓正面朝「前」
        找不到模型檔上傳了別的檔，例如 SVG 或截圖重新匯出 .OBJ
        劍在錯的那隻手攻擊遊戲以比較長的那隻手當武器手把要攻擊的那把武器做長一點

        🆘 卡住了怎麼辦

        先按 Ctrl＋Z 復原，切到「上」「前」視角看看，還是不行再舉手問老師。
